# Assignment 3: Bigram Language Model with Rule-Based Post-Processing

## Overview
Implements a character/word-level Bigram language model with Laplace smoothing and text generation, enhanced with a `tkinter` interface and rule-based post-processing options.

## Files
- `baseline_bigram.py` — Starter script provided for the assignment.
- `bigram_text_generator.py` — Modified implementation with `tkinter` UI and rule-based post-processing.
- `report_bigram_postprocessing.pdf` — Course presentation slides explaining the model, post-processing rules, and outputs (in Traditional Chinese).
