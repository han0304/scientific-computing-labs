# Assignment 1: 3D Three-Body Gravitational Simulation (RK4)

## Files
- `baseline_two_body.py`: Starter script provided in class implementing a simplified 2-body visualization.
- `three_body_rk4_sim.py`: Modified implementation extending the simulation to 3 bodies using the 4th-order Runge-Kutta (RK4) method, with interactive `tkinter` inputs, reset functionality, and 3D trajectory animation.
- `report_three_body_rk4.pdf`: Presentation slides explaining the numerical method, code modifications, and simulation results (in Traditional Chinese).
