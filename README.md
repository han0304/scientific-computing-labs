# Scientific Computing Coursework

A collection of Python projects and numerical computing assignments from a university Scientific Computing course, organized to show the progression from starter/baseline code to modified implementations and visual/analytical reports.

## Repository Structure

- `assignment-01-three-body-rk4/` — 3D three-body gravitational simulation using the 4th-order Runge-Kutta (RK4) method with an interactive `tkinter` GUI and 3D `matplotlib` animation.
- `assignment-02-wavelet-compression/` — 2D Daubechies wavelet decomposition, high-frequency coefficient zeroing for compression, compression ratio evaluation, and reconstruction error visualization.
- `assignment-03-bigram-postprocessing/` — Bigram statistical language model with Laplace smoothing, text generation, and toggleable rule-based post-processing in `tkinter`.
- `extras/` — Early standalone practice script (`simple_calculator.py`).

## Tech Stack

- **Language:** Python
- **Libraries:** `numpy`, `matplotlib`, `tkinter`
